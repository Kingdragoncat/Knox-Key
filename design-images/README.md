design-images/

Place your project photos and screenshots in this folder so they appear in the repo alongside `README.md` and `JOURNAL.md`.

Filename conventions (used in this repo):
- 01_hkdf_code.png — hkdf.c screenshot (HKDF extract/expand functions)
- 02_bom_layout.png — KiCad BOM + board overview (top/bottom)
- 03_usb_pads_closeup.png — USB contact pad / edge connector close-up
- 04_top3d_closeup.png — 3D top view close-up (components near MCU)
- 05_swd_header.png — SWD / debug header pads with labels
- 06_nucleo_reference.png — STM32 Nucleo board reference image
- 07_header_pins_3d.png — 3D render of header pins / connector
- 08_knox_preview.png — README / LionKey feature excerpt screenshot
- 09_crystal_caps.png — crystal + load capacitor notes
- 10_swd_symbol.png — SWD symbol / header in schematic
- 11_user_button.png — user presence button circuit
- 12_power_reg.png — LDO regulator circuit
- 13_usb_esd.png — USB connector and ESD protection screenshot
- 14_atecc_i2c.png — ATECC608 I2C schematic

How to add images:
1. Upload image files to this folder in the repo (GitHub web UI: Add file → Upload files), or
2. Paste them here in the chat and ask me to add them — I can save and commit them for you.

After images are uploaded, `JOURNAL.md` will link to them from the **Design Images** section.
